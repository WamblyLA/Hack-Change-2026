# PSB Legal RAG

RAG-система для поиска и анализа юридической информации в рамках кейса ПСБ
Система отвечает на вопросы по корпоративным документам и нормативным актам, используя предоставленную базу знаний

## Архитектура

1. **Подготовка документов.** Загрузка базы знаний из ZIP-архива, очистка текста и разбиение нормативных актов на фрагменты
2. **Hybrid Retrieval.** Поиск релевантных фрагментов с использованием BM25, символьного TF-IDF и векторного поиска на BGE-M3
3. **Rank Fusion.** Объединение результатов нескольких поисковых методов с помощью Reciprocal Rank Fusion (RRF)
4. **Reranking.** Дополнительное ранжирование кандидатов моделью Qwen3 Reranker
5. **Evidence Bundling.** Добавление связанных договоров, дополнительных соглашений и редакций документов в контекст ответа
6. **Answer Generation.** Генерация ответа языковой моделью DeepSeek с использованием найденных источников
7. **Citations.** Преобразование внутренних ссылок на фрагменты в названия документов и положения источников

При недоступности эмбеддингов или reranker система может использовать лексический поиск

## Запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка данных

Разместите в папке `data/` два файла:
```text
- knowledge-base.zip
- questions.csv
```
`knowledge-base.zip` содержит документы для поиска. `questions.csv` должен содержать столбцы `id` и `question`

### 3. Настройка API

Необходимые переменные окружения:

```env
LLM_BASE_URL=https://your-api-endpoint/v1
LLM_API_KEY=your-api-key
LLM_MODEL=your-generation-model
EMB_MODEL=BAAI/bge-m3
RERANKER_MODEL=your-reranker-model
```

### 4. Запуск решения

```bash
python solution.py
```

Программа загружает документы, формирует поисковый индекс, обрабатывает вопросы и сохраняет результаты в `submission.csv`

Формат выходного файла:
```csv
id,answer
1,"Ответ на первый вопрос"
2,"Ответ на второй вопрос"
```

## Используемые технологии

- **Python** — реализация пайплайна
- **BM25** — лексический поиск
- **TF-IDF** — символьный поиск
- **BGE-M3** — векторные представления текста
- **Reciprocal Rank Fusion** — объединение результатов поиска
- **Qwen3 Reranker** — повторное ранжирование документов
- **DeepSeek** — генерация ответов
- **NumPy, scikit-learn, HTTPX** — вычисления и взаимодействие с API

## Особенности решения

- Работа с корпоративными документами и нормативными актами
- Обработка дополнительных соглашений и различных редакций документов
- Учёт контекста диалога
- Формирование ответов с указанием источников
- Ограничение ответов сведениями из предоставленной базы знаний
- Обработка недоступности отдельных компонентов поискового пайплайна

## Ограничения

Качество ответа зависит от полноты базы знаний, корректности найденных фрагментов и работы языковой модели
